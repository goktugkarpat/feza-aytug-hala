# Feza, Bilbo ve Aytuğ Hala: Dev Ev Macerası

Aytuğ Hala Feza'ya sürpriz pasta hazırlarken Bilbo un torbasına burnunu sokup hapşırıyor; sihirli renkli şekerler havaya uçuyor ve
üçü minicik oluyor. Şekerlerin değdiği eşyalar canlanıp sevimli huysuzlara dönüşüyor. Feza, Bilbo ve Aytuğ Hala evin odalarını gezip
huysuzları neşelendiriyor, pastanın malzemelerini (un, yumurta, çilek, krema) topluyor.

- **Mutfak Masası** (merkez): pasta, gardırop, Bilbo'nun köşesi, çıkartma albümü, mini oyunlar, odalara giden kapılar
- **Oturma Odası**, **Mutfak**, **Buzdolabı** (her biri 3 alan + boss), **Pasta Krallığı** (final, 3 malzemeyle açılır)

Oynamak: `index.html`'ye çift tıkla ya da https://goktugkarpat.github.io/feza-aytug-hala/ adresini iPad'de Safari ile aç
(Paylaş › Ana Ekrana Ekle ile uygulama gibi, internetsiz çalışır). Parmakla dokun/sürükle, büyük düğmeyle vur.
